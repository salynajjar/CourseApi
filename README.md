# Course API

A simple RESTful Web API built using ASP.NET Core and Entity Framework Core.

## Description

Course API is a backend application that manages courses.
It provides CRUD operations and connects to a SQL Server database using Entity Framework Core.

## Technologies

- ASP.NET Core Web API (.NET 10)
- Entity Framework Core
- SQL Server
- Swagger / OpenAPI
- C#

## Features

- Get all courses
- Get course by ID
- Add new course
- Update course
- Delete course
- Search courses by title
- Filter courses by price
- Data validation
- Logging support
